Far partire l'applicazione
- aprire docker
- aprire il terminale e lanciare docker-compose up -d
- configurare lo start dell'app e far partire

Aggiungere un'API
- Aggiungere l'API sul controller
  - GET per prendere risorse
  - POST per aggiungere risorse
  - PUT per aggiornare risorse
  - DELETE per cancellare risorse
- Creare il metodo nel service
- (se serve validazione creare il validator se non esiste e creare il metodo per la validazione dell'oggetto in input)



Funzionamento dei componenti
- Controller: punto di ingresso delle API
- Service: dove avviene la logica
- Mapper: mappare da entity a DTO e viceversa
- Validator: validare gli oggetti di input
- Repository: interagire con il DB
